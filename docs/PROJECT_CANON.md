# LATTICE: THE EMPTY LEAGUE — Project Canon

## One-sentence definition

人の消えた世界を固定カメラ式3Dマップで旅し、選手を集め、7人制の陣形競技によって都市設備と交通網を再起動する、探索・会話・クラブ運営中心のスポーツRPG。

## North Star experience

- 状況が分からない無人世界をさまよう不安。
- 競技規約を理解していれば、次の土地でも通用する安心。
- 冷えた世界に対して、クラブハウスと仲間だけが徐々に居場所になる感覚。

## Fixed design

- PS1〜PS2期を想起させるローポリゴン3Dと、場面ごとの固定カメラ。
- 移動、探索、会話を主要コンテンツとする。
- 競技〈ラティス〉は7対7。コア、リレーノード、連携線、得点陣形を使う。
- 得点または設備起動には、複数選手による規定陣形の成立が必要。
- カードゲームの構築思考を、ロスター、役割、陣形、連携、地域メタへ翻訳する。
- 選手は永続的な人物。消費、合成素材化、同一人物の重複取得、シーズンリセットを行わない。
- 育成は際限のない数値上昇ではなく、役割、連携、地域適応、会話、探索能力を広げる。
- メインストーリーは他クラブとの共同作戦で進行し、通常対戦はエキシビジョン、交渉、相互理解の手段になる。
- クラブ経営はクレジット、電力、資材、信頼を中心とする軽量管理。リアルタイム待機、日課、煩雑な給与・装備管理を中心にしない。
- 静的配信可能なbrowser game。能力販売、選手ガチャ、所持枠課金、疲労回復課金を行わない。
- NFTは初期実装から除外し、将来も任意の記念品、外見、履歴証明層に限定する。

## Competition foundation

- フィールドは複数区画とリレーノードを持つ。
- コアを運ぶだけでは得点にならず、規定陣形を完成させる。
- 守備は連携線、ノード、陣形の頂点を主に崩す。
- 基本役割は Anchor、Relayer、Runner、Breaker、Warden、Conductor、Wild。
- 陣形候補は Triangle、Spear、Ring、Chain、Split、Spiral。
- 例外規則を変更するtraitは、試合全体で少数枠に制限する。
- 少人数・少戦術への圧縮は短期戦で強くても、遠征、疲労、解析、複合規約では不利になり得る。

## World

人々の大多数が消えた後も、リーグ端末、審判機構、競技設備、交通・電力配分システムが動き続けている。生存者と、過去の選手人格から再構築された登録残響体が存在する。地域端末は規約、需要、交通、市場、過去ログ、異常裁定を表示する。

## Separation boundary

元のカードRPG企画、LOWPASS、Residual Atlas、その他の既存ゲームとは別プロジェクトとして扱う。明示的な決定なしに、設定、コード、asset、収益化方針を共有しない。

## Not now

完全な7対7試合、オンライン対戦、procedural open world、production character art、本番音声、広告SDK、決済、NFT、外部選手市場、ライブサービス型シーズン。

## Change control

中核仕様の変更は `rule | previous | replacement | reason | affected consumers | migration | rollback` を記録する。数値調整や局所prototypeを正本変更と混同せず、current Mission中に暗黙変更しない。
